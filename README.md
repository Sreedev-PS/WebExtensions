# Nukari Profile Auto-Updater Extension

This extension automatically updates your Nukari profile description and resume every 20 seconds.

## How to Use

1. Place your resume file in the `resume` folder.
2. Build the extension (see below).
3. Load the extension in Chrome/Edge:
   - Go to `chrome://extensions` or `edge://extensions`.
   - Enable Developer Mode.
   - Click "Load unpacked" and select this folder.
4. The extension will run in the background and update your profile and resume.

## Building the Extension

1. Install Node.js from https://nodejs.org/
2. Open a terminal in this folder.
3. Run:
   ```cmd
   npm install
   npm run build
   ```

## Notes
- You must be logged in to Nukari in your browser for the extension to work.
- The extension will automate browser actions to update your profile and resume.
